# AIagents

A collection of AI-powered agents and assistants for small business automation.

## Projects

- **Front Desk Agent** — AI assistant for handling common enquiries, scheduling, and customer interactions
- **Bookkeeping Assistant** — Automated invoice processing and expense tracking
- **Marketing Copilot** — Content generation and social media scheduling
- **Support Bot** — FAQ handling and ticket triage

## Tech Stack

- HTML/CSS/JavaScript (static frontends)
- Python (backend agents)
- Deployed via GitHub Pages
